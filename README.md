# Zema Chat

Custom Android Telegram client (`com.zemachat.app`) with a Black & Gold theme.

## Features
- **Zema Social**: Built-in WebView browser with shortcuts, desktop mode & background playback
- **Watch Here**: Open YouTube, TikTok & Instagram links inside Zema Social
- **Photo Watermark**: Apply custom text or logo watermark before sending photos
- **Local Quick Replies**: One-tap saved reply templates stored locally
- **Price Card**: Quick item, price & delivery card generator
- **Data Saver**: Low mobile data auto-download preset by default
